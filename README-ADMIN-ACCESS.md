GeoNature Admin Panel

1. გაუშვი START_GeoNature.bat და გახსენი http://localhost:8787/.
2. მენიუდან გახსენი Admin Panel და შედი ადმინისტრატორის პაროლით.
3. admin.html-ზე დარჩები Control Center-ში: Feedback inbox, ვიზიტების/რეგისტრაციების/შესვლების სტატისტიკა და დადასტურებული შესყიდვების მიმოხილვა.
4. Feedback-ის სტატუსი შეგიძლია მონიშნო წაკითხულად ან გასწორებულად.

Server mode is required. Live Server / plain file preview cannot save server feedback or count visits.
