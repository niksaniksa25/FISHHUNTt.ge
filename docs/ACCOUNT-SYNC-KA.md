# ანგარიშის სინქრონიზაციის ჩართვა

საიტის განახლებები GitHub Pages-ზე ავტომატურად ქვეყნდება. მოწყობილობებს შორის პირადი მონაცემების გადატანას ცალკე ანგარიშების სერვისის გამოქვეყნებაც სჭირდება. პროექტი Cloudflare Workers Free-სთვისაა გამზადებული.

1. Cloudflare-ში გახსენი **Workers & Pages → Create application / Create Worker → Import a repository** და აირჩიე **niksaniksa25/FISHHUNTt.ge**, ტოტი **main**.
2. პროექტის სახელად მიუთითე **fishhunt-accounts**, ხოლო **Root directory** ველში — **cloudflare/accounts**. Deployment command არის **npx wrangler deploy**. ცალკე Build command საჭირო არ არის.
3. დააჭირე **Deploy**. საცავი და მისი მიბმა რეპოზიტორიაში მოთავსებული კონფიგურაციით შეიქმნება.
4. გახსენი **https://fishhunt-accounts.bsloveer25.workers.dev/api/health**. თუ პასუხში წერია **"accountConfigured": true**, განაახლე საიტი — სინქრონიზაცია ხელმისაწვდომი გახდება.

ანგარიშების ახალ სერვისს Gemini-ის გასაღები და ადმინისტრატორის პაროლი არ სჭირდება. არსებული **fishhunt-ai** სერვისი თავის ფუნქციებს აგრძელებს. ანგარიშების ახალი სერვისის სტატუსში `configured: false` და `adminConfigured: false` ნორმალურია; ანგარიშებისთვის მნიშვნელოვანია `accountConfigured`.

თუ Cloudflare სხვა საჯარო მისამართს მიანიჭებს, საჭიროა მისი მითითება `js/api-config.js`-ის `GN_ACCOUNT_WORKER_ORIGIN` პარამეტრში. ეს საჯარო მისამართია; გასააქტიურებლად მისი მოწერაც საკმარისია.

ჩართვის შემდეგ პროფილში ან შესვლის გვერდზე აირჩიე სინქრონიზაციის ანგარიში. ძველი ბრაუზერის ჩანაწერების გადატანა ცალკე არჩევანია. სხვა ტელეფონზე იგივე ანგარიშით შესვლისას პროფილისა და ჩანაწერების ჩამოტვირთვას შეძლებ. ფოტოები თავდაპირველ მოწყობილობაზე რჩება.

## პაროლის აღდგენა

სინქრონიზებულ ანგარიშში შესვლის შემდეგ გახსენი პაროლის აღდგენის განყოფილება და მიმდინარე პაროლის დადასტურებით შექმენი პირადი აღდგენის კოდი. შეინახე ის პაროლების მენეჯერში ან სხვა უსაფრთხო ადგილას — კოდი მხოლოდ ერთხელ გამოჩნდება. ახალი კოდის შექმნა ძველს გააუქმებს. არავის გაუგზავნო კოდი ან პაროლი.

პაროლის დავიწყებისას შესვლის ფორმაზე აირჩიე აღდგენა, მიუთითე ანგარიშის ელფოსტა, ადრე შენახული კოდი და ახალი პაროლი. აღდგენა ყველა მოწყობილობის სესიას გააუქმებს; ჩანაწერები და პროფილი შენარჩუნდება. შედი ახალი პაროლით და შექმენი ახალი აღდგენის კოდი. გამოყენებული კოდი მეორედ არ იმუშავებს.

ეს აღდგენა ელფოსტაზე წერილის გაგზავნას არ მოითხოვს. მხოლოდ ელფოსტის ცოდნით პაროლი ვერ შეიცვლება. ძველ ანგარიშში პირველი კოდის მოსამზადებლად ჯერ შესვლაა საჭირო. ლოკალური ბრაუზერის ანგარიში სინქრონიზებული ანგარიშისგან დამოუკიდებელია.

ფუნქცია ჩაირთვება ანგარიშების Worker-ის ახალი ვერსიის წარმატებით გამოქვეყნების შემდეგ: `/api/health` პასუხში უნდა გამოჩნდეს `"accountRecoveryConfigured": true`. GitHub-თან დაკავშირებულ Cloudflare პროექტში ცვლილება ჩვეულებრივი განახლებით ქვეყნდება; საცავის თავიდან შექმნა საჭირო არ არის.

ტექნიკური აღწერა და არსებული Worker-ის გაფართოების ალტერნატივა: [ACCOUNT-SYNC.md](ACCOUNT-SYNC.md).
