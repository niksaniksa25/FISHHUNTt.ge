# Character portrait avatars

Created for FishHunt on 2026-10-23 using OpenAI image generation. This collection replaces the previous scenic avatar mix with larger, expressive character portraits that remain recognizable in small profile pictures.

These are decorative generated illustrations, including imaginary woodland characters and a generic fictional adult angler. They do not portray real community members or document actual wildlife sightings or destinations.

Twenty independent 512×512 WebP assets share emerald and teal backgrounds, warm gold lighting, detailed natural textures and close-up compositions. Each existing avatar ID is retained so saved choices continue working. The previous collection remains available for cached site versions.

The original generated production sheet remains outside the repository at `/workspace/generated_images/exec-89df48c6-51cd-40c6-84e6-632c28066966.png`. WebP files were extracted from its actual panel boundaries and optimized for profile use.
