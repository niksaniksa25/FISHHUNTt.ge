# Illustrated avatar collection

Created for FishHunt on 2026-10-22 using OpenAI image generation. These are decorative, generated illustrations; they are not documentary wildlife photographs or portraits of real community members.

The twenty independent 384×384 WebP assets share an emerald, copper and gold nature art direction. Individual square assets were extracted from the generated contact sheet and optimized for small profile pictures. Existing avatar IDs are retained so saved selections keep working.

The original production sheet is retained outside the repository at `/workspace/generated_images/exec-245db35a-b943-4d13-843f-d46b02cc5f37.png`.
