# Phone artwork

Created for FishHunt on 2026-10-22 with OpenAI image generation; no external runtime image service is required.

- `river-avatar.webp`: decorative fish, river and mountain illustration for the default community avatar and phone AI assistant.
- `mountain-lake.webp`: generated decorative mountain landscape for the phone welcome area and default profile background. It does not document a specific Georgian destination.

The optimized WebP files are used by the site; the original generated images remain outside the repository in `/workspace/generated_images`.
