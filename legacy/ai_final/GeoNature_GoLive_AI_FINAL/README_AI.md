# GeoNature Georgia — AI + Optimized Map

## მთავარი ცვლილებები
- `birds.html` და `birds.js` ამოღებულია.
- დაემატა `ai.html` + `js/ai.js`.
- AI-ს აქვს 753 მზა კითხვის ფორმა/შაბლონი და თემატური კატეგორიები.
- კითხვები: სახეობები, ფრინველები, ცხოველები, თევზები, ამინდი, რუკა, უსაფრთხოება, საიტის გამოყენება.
- საკუთარი კითხვის დაწერა და Enter-ით გაგზავნა.
- მზა კითხვაზე დაჭერით პასუხი პირდაპირ ჩატში ჩნდება.
- რუკა ოპტიმიზებულია: ნაკლები მარკერი, ძებნისას ძველი შედეგის ავტომატური ჩანაცვლება, Leaflet animation გამორთულია, tile buffer შემცირებულია.
- საქართველოს სოფლებისა და ქალაქების ძებნა რჩება OpenStreetMap Nominatim-ით.
